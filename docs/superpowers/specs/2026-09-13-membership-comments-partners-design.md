# 某不知名有用的网站第二期设计规格：会员、评论、合作商与打赏

- 日期：2026-09-13
- 状态：已完成设计讨论，等待用户审阅
- 前置版本：2026-09-12 第一期设计规格
- 本期范围：登录跳转修复、会员体系、评论审核、合作商推广、余额提现、打赏入口
- 部署目标：继续使用 GitHub Pages + Cloudflare Workers、D1、Workers KV 免费套餐

## 1. 第二期目标

第一期已经上线公共网站、账号系统、课程密码、付款申请、视频播放、观看进度和站长后台。第二期扩展现有系统，使用户可以购买会员、评论商品、成为合作商并获得推广佣金，同时为站长和合作管理员提供打赏入口。

第二期需要实现：

- 登录后默认进入首页，而不是用户中心。
- 用户中心分开显示身份角色、会员等级、合作等级和会员剩余天数。
- 普通用户、VIP、SVIP 三档会员权益与折扣。
- 所有产品可评论，普通/VIP 评论审核，SVIP 免审核。
- SVIP 连续评论过多时，后续评论仅作者可见 1 小时，然后永久删除。
- 合作商一次性开通、推广码、订单归属、预估佣金、余额和提现申请。
- 站长和合作管理员打赏入口。
- 站长完整权限，顶级合作商仅拥有评论审核与合作中心权限。

## 2. 用户身份模型

系统将“身份角色”“会员等级”“合作等级”分成三个独立维度。

### 2.1 身份角色

| 角色 | 权限 |
| --- | --- |
| owner | 站长，拥有全部权限 |
| admin | 管理员，目前只对应顶级合作商，拥有全站评论审核和合作中心权限 |
| user | 普通网站账号，无后台管理权限 |

第一期已有的 admin 账号迁移为 owner，保留原用户名、密码和 id。合作管理员不能访问用户管理、收入统计、订单审核、安全设置或其他站长专属页面。

### 2.2 会员等级

| 等级 | 价格 | 有效期 | 折扣 | 评论权限 |
| --- | --- | --- | --- | --- |
| normal | 免费 | 无 | 原价 | 评论需审核 |
| vip | 9.9 元 | 30 天 | 全场商品 8 折（会员费和分站费除外） | 评论需审核，显示 VIP |
| svip | 19.9 元 | 30 天 | 全场商品 5 折（会员费和分站费除外） | 免审核，显示 SVIP |

### 2.3 合作等级

| 等级 | 一次性开通费 | 站长分成 | 合作商分成 | 评论审核 |
| --- | --- | --- | --- | --- |
| none | 无 | 100% | 0% | 无 |
| basic | 0.01 元 | 50% | 50% | 无 |
| advanced | 1 元 | 10% | 90% | 无 |
| top | 9.9 元 | 0% | 100% | 全站评论审核 |

合作等级与会员等级互不影响。一个用户可以同时是 SVIP 与顶级合作商。

## 3. 登录与显示修复

- 登录成功后，如果登录地址没有 returnTo，默认跳转首页。
- 从受保护页面跳转登录时，继续返回原页面。
- 用户中心将身份角色、会员等级、合作等级分开显示。
- 用户中心显示会员到期时间和剩余天数，例如“会员剩余 23 天”。
- 剩余 7 天以内时突出显示续费提醒。
- 评论区用户名旁统一显示：
  - 会员等级标识：VIP 或 SVIP。
  - 管理员标识：合作管理员。
  - 会员剩余天数。
- 没有会员或合作身份时只显示用户名，不显示空占位。

## 4. 会员规则

### 4.1 购买与续费

- 用户通过收款码支付会员费，并提交付款截图。
- 站长审核通过后，系统设置会员等级和到期时间。
- 同一等级提前续费时，在现有到期时间上增加 30 天。
- 会员到期后自动恢复为普通用户，不需要定时任务；每次读取当前用户时根据到期时间计算实际等级。
- VIP 升级 SVIP 时，从审核通过时开始计算 30 天，原 VIP 剩余时间不折算。
- SVIP 不允许直接降级为 VIP；SVIP 到期后可再购买 VIP。
- 同一时间只保留一个有效会员等级。

### 4.2 折扣范围

会员折扣适用于：

- 火影课程和其他课程。
- 未来的数字产品。
- 未来的虚拟商品。

会员折扣不适用于：

- VIP 和 SVIP 会员费。
- 合作商分站开通费。
- 人工服务费。
- 打赏。

折扣在创建付款申请时由服务端计算并快照，用户界面不能自行修改价格。合作商佣金按用户折后实际到账金额计算。

### 4.3 金额精度

- 所有金额统一使用整数“分”存储。
- 现有 29 元、49 元迁移为 2900 分、4900 分。
- 现有实际到账金额字段迁移为分。
- 显示时统一格式化为两位小数。
- 折扣和佣金使用四舍五入到分的规则。

## 5. 评论与审核规则

### 5.1 评论范围

- 课程和未来数字产品支持各自独立的评论；会员购买、免费资源专区和人工服务不展示评论。
- 评论数量不限。
- 第一版评论只支持纯文本。
- 第一版不做回复、点赞、图片评论和星级评分。
- 评论始终绑定对应产品。

### 5.2 普通用户和 VIP

- 评论提交后状态为 pending，仅作者本人可见。
- 作者可以看到“审核中”。
- 站长或管理员审核通过后状态为 public，所有访客可见。
- 审核拒绝后状态为 rejected，仅作者可见未通过状态。
- 已拒绝评论不占用公开评论列表。

### 5.3 SVIP

- SVIP 评论提交后直接公开，不需要审核。
- 评论发布后立即显示“发布成功”。
- 评论用户名旁显示 SVIP 与会员剩余天数。
- VIP/SVIP 状态在评论展示时按当前有效会员状态动态计算。

### 5.4 SVIP 连续评论保护

- 以固定 10 分钟窗口为准；采用原子计数，边界处可能允许短时间跨窗口连续公开。
- 每个 SVIP 的前 3 条评论正常公开。
- 第 4 条及之后的评论记录为 author_only。
- 作者提交后仍看到“发布成功”，刷新后也能在自己的评论列表中正常看到。
- 其他用户看不到 author_only 评论。
- 页面不提示审核、刷屏、隐藏或失败。
- 后台不显示“刷屏”或“仅作者可见”文字标签。
- author_only 评论创建后保留 1 小时。
- 每小时定时任务永久删除超过 1 小时的 author_only 评论。
- 公开评论不会被自动删除。

### 5.5 评论管理

- 站长和顶级合作商管理员可以审核 pending 评论。
- 审核动作包括通过和拒绝。
- 已发布评论只允许删除，不提供隐藏或恢复操作。
- author_only 评论不进入人工审核队列，1 小时后自动删除。
- 评论删除、审核和拒绝均记录操作人和时间。
- 管理员只能执行评论权限，不能查看用户管理、收入统计和站长安全设置。

## 6. 合作商与推广码

### 6.1 开通

- 任意登录用户可以进入合作中心申请合作等级。
- 合作等级包括 basic、advanced、top 三种。
- 用户选择等级，扫码支付一次性开通费并提交付款截图。
- 站长审核通过后，系统创建合作商资料、分配唯一推广码并启用合作权限。
- 开通费不续费，不参与佣金和折扣。
- 审核拒绝时保存拒绝原因。

### 6.2 推广码

- 推广码在注册时是选填项，和手机号、邮箱一样。
- 用户注册后可以在用户中心更换推广码。
- 不同合作商可以争夺同一用户，站方不限制更换。
- 每次订单创建时记录当时账号绑定的推广码快照。
- 订单提交后归属锁定；之后更换推广码不影响已创建订单。
- 注册时没有填写推广码，之后仍可以补填或更换。
- 自己绑定自己的推广码无效。
- 无效或不存在的推广码不会产生佣金。
- 推广码只用于订单归属，本身不产生收益。

### 6.3 订单归属

- 用户提交任何符合条件的商品订单时，系统读取当前推广码。
- 订单保存合作商 id、推广码快照、佣金比例和预估佣金。
- 付款申请尚未审核时，合作商后台显示：
  - 预估到账金额。
  - 状态“审核中”。
- 站长审核通过订单后，佣金状态改为 available，可提现。
- 站长拒绝订单后，佣金状态改为 rejected，并显示拒绝原因。
- 付款申请因对方没有下单而拒绝时，合作商看到“审核未通过，原因：对方没下单”。

### 6.4 佣金范围

佣金适用：

- 课程销售。
- VIP 和 SVIP 会员费。
- 其他数字产品和虚拟商品。

佣金不适用：

- 合作商开通费。
- 打赏金额。
- 人工调整金额。
- 没有真实付款的订单。

佣金按用户实付金额计算：

- basic：合作商获得 50%。
- advanced：合作商获得 90%。
- top：合作商获得 100%。

### 6.5 合作商余额与提现

- 佣金只有在订单审核通过后才进入可提现余额。
- 合作中心显示预估金额、审核中金额、可提现余额、已提现金额和冻结金额。
- 合作商点击“申请提现”，填写收款方式和收款信息。
- 提现申请创建后，对应余额冻结，防止重复提现。
- 站长在后台查看提现申请，手动转账后标记“已打款”。
- 站长拒绝提现后，冻结金额退回到余额。
- 提现操作保留申请、审核、打款和拒绝记录。
- 第一版没有自动打款接口。
- 已提交提现的佣金订单金额锁定，不允许再修改实际金额，从而避免负数余额。
- 正常流程不允许出现负余额。

### 6.6 合作商后台权限

- 合作商可以看到自己推广用户的订单、佣金、余额和提现记录。
- 合作商不能查看全站订单、全站总收入、其他合作商或用户密码信息。
- basic 和 advanced 合作商没有评论审核权限。
- top 合作商拥有管理员身份，只增加评论审核和合作中心权限。
- 站长可以停用合作商推广码。
- 停用前产生的可用余额仍可提现；停用后新订单不再产生佣金。

## 7. 打赏功能

### 7.1 打赏站长

- 公共页脚和用户中心显示“打赏站长”按钮。
- 点击后展示站长的微信和支付宝收款码。
- 站长打赏复用付款页面的两张收款码图片。
- 提示用户打赏属于自愿支持，不对应商品权益。
- 第一版打赏不保存付款截图，不自动确认到账，不产生订单和收入统计。

### 7.2 打赏管理员

- 页面提供“打赏管理员”按钮。
- 点击后打开管理员目录，支持按用户名搜索。
- 目录包含站长和所有顶级合作商管理员。
- 点击具体管理员后，显示“该管理员打赏渠道暂未开放”。
- basic 和 advanced 合作商不出现在管理员打赏目录。
- 后续开放时，每位管理员可以配置自己的微信和支付宝收款码。
- 打赏金额不参与会员折扣、合作商佣金、订单收入或合作商提现余额。

## 9. API 与页面

### 9.1 用户页面

- 登录页：默认返回首页；有 returnTo 时返回原页面。
- 用户中心：分开显示三类身份、会员到期与剩余天数。
- 会员购买页：VIP、SVIP、续费和升级。
- 合作中心：申请合作等级、推广码更换、推广订单、佣金余额和提现。
- 产品评论：发布、审核状态、自己的 author_only 评论。
- 打赏站长和管理员目录。

### 9.2 站长后台

- 会员订单审核。
- 会员等级和到期时间修正。
- 评论审核和删除。
- 合作商申请审核。
- 推广订单和佣金明细。
- 提现审核、标记打款和拒绝。
- 合作商停用/启用。
- 打赏不需要站长订单管理。

### 9.3 合作管理员后台

- 只能访问评论审核。
- 只能访问自己的合作中心。
- 可以查看自己的推广订单、佣金余额、冻结金额和提现状态。
- 不能访问用户管理、订单审核、收入统计、安全设置和全部审计记录。

## 10. 权限与安全

- owner 是唯一拥有全站管理权限的角色。
- admin 角色的服务端权限仅限评论审核；合作中心数据按 partner_id 隔离。
- user 只能访问自己的账号、订单、评论和合作资料。
- 推广码更换记录、佣金生成、订单修改、提现和评论删除全部写审计日志。
- 自己不能推广自己，不能给自己生成佣金。
- 没有付款的订单不能生成可提现佣金。
- 提现冻结使用原子 D1 操作，防止重复申请。
- 已提交提现的订单实际金额锁定。
- 管理员不能查看其他合作商数据。

## 11. 定时任务

- 每小时执行一次 author_only 评论清理。
- 删除条件：status = author_only 且 visible_until <= 当前时间。
- 删除为永久删除。
- 定时任务同时清理过期的 rate_limits 记录，减少 D1 冗余数据。
- 会员到期不依赖定时任务，在读取用户时动态计算。

- 可提现余额和冻结余额计算正确。
- 提现重复提交会被阻止。
- 站长标记打款后余额状态正确。
- 完成提现的订单不能修改实际金额。
- 基础、高级、顶级佣金比例分别为 50%、90%、100%。
- 打赏站长时显示两种收款码。
- 管理员打赏目录支持搜索，渠道打开后显示暂未开放。
- 合作管理员不能访问站长专属页面。

## 14. 不在本期范围

- 自动续费。
- 自动打款和提现支付接口。
- 管理员打赏渠道开放和收款码上传。
- 评论回复、点赞、图片和评分。
- 多租户独立分站。
- 分站级数据库和自定义域名。
- 退款系统。
- 合作商保证金、发票、税务和自动结算报告。

## 15. 完成定义

第二期只有同时满足以下条件才算完成：

- 四个阶段全部上线。
- 现有账号和课程数据迁移成功。
- 站长、合作管理员和普通用户权限隔离正确。
- 会员、评论、佣金、余额、提现和打赏流程通过端到端测试。
- 现有课程购买、课程密码、视频播放和第一期功能没有回归。
- 所有金额使用分存储和显示。
- 所有敏感操作有审计记录。
- 部署文档和运营文档同步更新。
